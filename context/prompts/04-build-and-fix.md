# Name: BUILD-FIX
**Use when:** a coding agent must get the tree building and testing green on a
fresh machine.

---

In `source/`, make this build and test green on a clean Linux machine, without
changing behaviour. Read `context/CONTEXT.agent.md` and
`context/04-BUILD-VERIFY.md` first — two blockers are already documented:

1. `build/font8x16.h` is generated by `tools/gen_font.py`, which needs **Pillow**,
   and is not committed. `microlm_weights.h` is generated **and** committed;
   mirror that pattern. Commit the generated table, keep the generator, and make
   `make` work with **no Python packages** installed.
2. `struct sched_param` is double-defined on glibc ≥ 2.36 (already fixed in
   `src/ksched.c` and `boot/probe.c`; do not reintroduce
   `<linux/sched/types.h>` alongside `<sched.h>` anywhere).

Then, in this order:

1. `make -j4` → warning-free (the v1.0 flag set: `-Wall -Wextra -Wshadow
   -Wformat -Wformat-security -fstack-protector-strong -D_FORTIFY_SOURCE=2`).
2. `make test` → all 11 suites pass **from `source/`**, with `tool-exec`
   discoverable (see Trap 2 in `context/CONTEXT.agent.md`). If a suite fails
   only because the environment lacks a facility (Landlock, eBPF), it must print
   a `SKIP` with the reason — never a silent pass, never a disabled check.
3. Fix the stale numbers in `README.md` and `INSTALL.md` ("10 suites",
   "10 passed") to match reality (11), and remove or correct references to
   `scripts/*.sh` and `download/m10-boot-shots/` that do not exist.
4. Add `.github/workflows/ci.yml` that runs `make && make test` on a clean
   Ubuntu runner (no root, no network beyond apt for gcc/make).
5. Verify `.gitignore` keeps `*.o`, `*.d`, `build/` and runtime stores out of
   git; `git status` must be clean after a full build and test run.
   (`source/boot/dl/` is *deliberately tracked* — the offline build needs it;
   do not ignore it, and keep large binaries out of future commits instead.)

Constraints: no new runtime dependency, no behavioural change, no test
weakened, no size-cap change to the image. Report at the end: exact commands
run, pass/fail counts, and any file you could not fix with the reason.
Update `context/04-BUILD-VERIFY.md` with the new results.
